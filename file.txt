Write this INSIDE Home() component, near your isValidEmail helper.

// Password strength validation
const isStrongPassword = (password) => {
  const regex =
    /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[@$!%*?&])[A-Za-z\d@$!%*?&]{8,}$/;
  return regex.test(password);
};

#CSS
📦 Layout & Position

display → element ka layout behavior define karta hai

position → element screen/container ke hisaab se place karta hai

top / right / bottom / left → positioned element ka exact location

z-index → layers ka order decide karta hai

float → element ko left/right flow me le jata hai

clear → float ka effect remove karta hai

📐 Box Model

margin → element ke bahar ka space

padding → element ke andar ka space

border → element ka outline

box-sizing → width/height calculation rule set karta hai

🎨 Colors & Background

color → text ka color

background → background shortcut property

background-color → background ka color

background-image → background image set karta hai

background-size → image ka size control karta hai

background-position → image ki position

background-repeat → image repeat behavior

✍️ Text & Font

font-family → font type set karta hai

font-size → text ka size

font-weight → text ki thickness

font-style → italic/normal text

text-align → text alignment

text-decoration → underline/line-through

line-height → lines ke beech space

letter-spacing → letters ke beech gap

📏 Size

width / height → element ka size

max-width / min-width → responsive limits

overflow → content overflow handle karta hai

🧭 Flexbox

display: flex → flex layout enable karta hai

flex-direction → row ya column flow

justify-content → main axis alignment

align-items → cross axis alignment

gap → items ke beech space

📐 Grid

display: grid → grid layout activate karta hai

grid-template-columns → columns define karta hai

grid-template-rows → rows define karta hai

place-items → alignment shortcut

🎬 Effects & Animation

opacity → transparency control

transition → smooth property change

transform → rotate/scale/move element

animation → keyframe based motion

box-shadow → shadow add karta hai

🖱️ Interaction

cursor → mouse pointer type

pointer-events → click enable/disable

user-select → text select control

📱 Responsive

@media → screen size ke according styles

vw / vh → viewport based units

% → relative sizing


“Kitna px ya % likhna hai – kaise pata chale?”

px → jab exact size chahiye (icons, borders, buttons height)

% → jab parent ke according responsive size chahiye

vw / vh → screen ke according size chahiye (hero sections)

rem → text + spacing scalable rakhna ho (best practice)

em → parent text ke relative sizing chahiye

📌 Rule of Thumb (yaad rakhne layak)

Text → rem

Padding/Margin → rem or %

Layout width → % / vw

Height fixed ho → px

Full screen section → 100vh
